# 全國電子｜延長保固表單產生器

一個純前端、免安裝、可離線使用的延長保固海報表單產生工具。

## 功能特色

- 支援多種商品類別方案（家電、3C、空調等）
- 根據商品金額自動計算延保費用
- 即時預覽 A4 表單（A4 全版 / 雙拼 / 四拼 / 八拼）
- 一鍵列印或匯出為 Word (.docx) 檔案
- 可匯入自訂 CSV 價格表
- 8 個分頁暫存，資料自動儲存於瀏覽器
- 每日／每月換算顯示

## 使用方式

直接開啟網頁即可使用，無需安裝任何軟體：

👉 **[點此開啟工具](https://你的帳號.github.io/你的Repo名稱/)**

或下載 `index.html` 後，用瀏覽器開啟（雙擊檔案即可）。
